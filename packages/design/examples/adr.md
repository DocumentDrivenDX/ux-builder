# ADR-001: What should anglers see first?

## Problem

What should anglers see first?

## Decision

We will map first.

## Why We Chose This

- Anglers think in places, and access points are spatial

### Over List first

Considered and not chosen, for the reasons above.

## Consequences

**Good**: Anglers think in places, and access points are spatial.

**Trade-offs**: List first is set aside.

## Assumptions

- Location is available on most phones

## Validation

**Result**: not tested
**Evidence**: none yet
**Required**: A comparative usability test
