# Writing a ux evaluation report

One evaluation's results: method, tasks, measures, the rubric with predicted and observed columns, findings by journey, state coverage and recommendations. From the usability-evaluation-report type proposed to HELIX (docs/proposals/helix-ux-artifact-types); it becomes HELIX's type in stage 2 (H-1).

Report only what the method supports: an inspection does not report task
success rates; five participants are not a population. Label every finding as
a human observation or an agent recommendation. In the rubric, keep predicted
and observed side by side and never average them.

`ux-builder-design report` drafts it from the design state, the rubric, the latest assessment run and the test kits; say what was not tested. Use `template.md`; `example.md` shows a finished one. `ux-builder-design validate` checks it.
