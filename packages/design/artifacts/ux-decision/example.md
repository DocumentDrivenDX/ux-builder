# UXD-1: What should users see first?

## Question

What should users see first when they open River Path?

## Alternatives

- Search first
- Map first
- Activity first

## Recommendation

Map first, with search on the map.

## Rationale

- Supports immediate exploration.
- Reduces initial decisions.
- Gives geographic context.

## Assumptions

- Location is available or easily chosen.
- Map performance is acceptable on a phone.

## Validation

- **Status**: not-tested
- **Required**: comparative usability testing of map first and search first
