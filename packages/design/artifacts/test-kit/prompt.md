# Writing a usability test kit

Everything needed to test the journeys with real people: tasks phrased as goals with no interface words, success criteria from the acceptance criteria, a facilitator script, a consent note, a screener and an observation sheet.

Phrase each task as the user's goal, never naming a screen, a control or a
label. Take success criteria from the journey's acceptance criteria. Keep the
script neutral: no leading questions, no help unless the participant is stuck
for two minutes, then note the assist.

Use `template.md`; `example.md` shows a finished one. `ux-builder-design validate` checks it.
